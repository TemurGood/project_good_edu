# Инструкция: Настройка глобального RAG через Google Docs (.docx), Excel / Google Sheets (.xlsx) и Google Cloud Console

В проекте уже сгенерированы готовые файлы для загрузки в Google Drive:
- **`good_edu_price.docx`** — прайс-лист (14 курсов, цены в сумах, условия рассрочки 0%).
- **`good_edu_faq.docx`** — часто задаваемые вопросы (8 подробных ответов).
- **`good_edu_schedule.xlsx`** (и **`good_edu_schedule.csv`**) — таблица Excel с данными всех преподавателей, направлениями, расписанием по дням недели, статусами окон (`Свободно` / `Занято`) и записанными студентами.

После любого изменения в этих документах агент (`gemini-3.5-flash-lite`) автоматически подтягивает свежие данные, пересчитывает векторы (`gemini-embedding-001`), ищет свободные окна и записывает студентов прямо в таблицу.

---

## Способ 1. Настройка через https://console.cloud.google.com (Google Sheets API + Google Drive/Docs API)

Используйте этот способ, если вы хотите подключаться напрямую через официальные REST API Google Cloud:

### Шаг 1. Создание проекта и включение API
1. Перейдите в **[Google Cloud Console](https://console.cloud.google.com/)**.
2. В верхней панели нажмите на выпадающий список проектов -> **New Project (Новый проект)** -> назовите его `Good-Edu-RAG` и нажмите **Create**.
3. В левом меню выберите **APIs & Services -> Library (Библиотека API)** и включите 3 сервиса (нажмите **Enable** на каждом):
   - **Google Drive API** (для чтения `.docx` документов и экспорта текста в реальном времени)
   - **Google Docs API** (для чтения структуры документов Google Docs)
   - **Google Sheets API** (для чтения расписания преподавателей и записи студентов в таблицу)

### Шаг 2. Создание учётных данных (API Key и OAuth 2.0 / Service Account)
1. Перейдите в **APIs & Services -> Credentials (Учётные данные)**.
2. **Для мгновенного чтения документов и таблиц:**
   - Нажмите **+ CREATE CREDENTIALS -> API key**.
   - Скопируйте созданный ключ (`AIzaSy...`). По желанию в настройках ключа ограничьте его тремя включёнными API (*Google Drive API, Google Docs API, Google Sheets API*).
3. **Для записи студентов в таблицу напрямую из браузера (OAuth 2.0 Client ID):**
   - Перейдите в **OAuth consent screen**, выберите **External**, укажите название `Good Edu CMS` и ваш email.
   - В разделе **Scopes** добавьте область `https://www.googleapis.com/auth/spreadsheets`.
   - Вернитесь в **Credentials -> + CREATE CREDENTIALS -> OAuth client ID**:
     - Application type: **Web application**
     - Authorized JavaScript origins: укажите адрес вашего локального сервера или домена (например, `http://localhost:3000`, `http://127.0.0.1:5500` или ваш домен на Vercel).
   - Скопируйте полученный **Client ID** (`...apps.googleusercontent.com`).

### Шаг 3. Публикация документов на Google Диске
1. Загрузите `good_edu_price.docx`, `good_edu_faq.docx` и `good_edu_schedule.xlsx` на ваш [Google Drive](https://drive.google.com/).
2. Откройте каждый файл -> нажмите **Файл -> Сохранить как Документы Google / Таблицы Google** (или оставьте доступ по ссылке).
3. Нажмите кнопку **Поделиться (Share)** в правом верхнем углу каждого из трёх файлов:
   - Для чтения по API-ключу: выберите **«Все, у кого есть ссылка» -> Читатель (Viewer)**.
   - Для записи студентов в таблицу без серверного бэкенда: выберите **Редактор (Editor)** или используйте Web App мост ниже.
4. Скопируйте **ID документа** из адресной строки браузера:
   - Пример ссылки: `https://docs.google.com/document/d/1aBcDeFgHiJkLmNoPqRsTuVwXyZ/edit`
   - ID файла: `1aBcDeFgHiJkLmNoPqRsTuVwXyZ`

## Способ 2. Самый быстрый и надёжный вариант для записи в таблицу без OAuth-окон — Google Apps Script Bridge (1 минута)

Так как браузерный `fetch` без OAuth-авторизации пользователя не может делать `POST /append` напрямую в чужую Google Таблицу, Google предоставляет встроенный бесплатный серверный вебхук **Google Apps Script** прямо внутри вашей таблицы:

1. Откройте вашу таблицу `good_edu_schedule` в **Google Таблицах**.
2. В верхнем меню нажмите **Расширения (Extensions) -> Apps Script**.
3. Скопируйте код из файла [`google_apps_script_bridge.gs`](./google_apps_script_bridge.gs) и вставьте его в редактор скриптов.
4. В первых двух строках скрипта вставьте ID ваших документов `PRICE_DOC_ID` и `FAQ_DOC_ID`.
5. Нажмите синюю кнопку **Начать развертывание (Deploy) -> Новое развертывание (New deployment)**:
   - Выберите тип (шестерёнка): **Веб-приложение (Web app)**.
   - **Запуск от имени (Execute as):** *Меня (Me)*.
   - **У кого есть доступ (Who has access):** *Все (Anyone)*.
6. Нажмите **Развернуть (Deploy)**, подтвердите доступ и скопируйте полученную ссылку вида:
   `https://script.google.com/macros/s/AKfycb.../exec`
7. Вставьте эту ссылку в **Админ-панели сайта Good Edu -> вкладка «📅 Excel Расписание & Cloud RAG»**!

## Как работает автоматическое обновление RAG и запись студентов

1. **Авто-синхронизация (Live Polling + Sync on Open):**
   - Каждые 30 секунд (а также по кнопке «🔄 Синхронизировать с Google Cloud» и перед каждым ответом агента) сайт запрашивает свежие данные из ваших Google Docs (`.docx`) и Google Sheets (`.xlsx`).
   - Если хеш содержимого изменился, RAG-движок автоматически пересобирает чанки и обновляет векторы через `gemini-embedding-001`.
2. **Поиск свободных окон и запись через AI-агента (`gemini-3.5-flash-lite`):**
   - Студент пишет в чат: *«Какие есть свободные окна по Full-Stack или у Азизбека?»* — агент видит актуальную таблицу и перечисляет все слоты со статусом **`Свободно`**.
   - Студент пишет: *«Запиши меня к Азизбеку на понедельник 19:30, меня зовут Алишер, телефон +998 90 555-44-33»* — агент распознаёт намерение записи, автоматически бронирует окно `SLOT-102` в таблице (меняет статус на **`Занято`**, записывает имя и телефон студента, отправляет `POST` в Google Таблицу и добавляет заявку в Админ-панель).
   - Если другой студент после этого спросит про окна к Азизбеку, слот `Понедельник 19:30` уже будет занят, и агент предложит только оставшиеся свободные окна!
